# 使用指南

本文按日常使用顺序介绍界面与行为。部署和配置见 [配置参考](configuration.md)。

## 1. 登录与仪表盘

用 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 登录。连续 5 次密码错误会锁定 5 分钟。
仪表盘展示：

- 账号分享率、上传/下载量、魔力值（来自 M-Team `/member/profile`）；
- 今日 API 预算用量；
- 磁盘水位与硬链接前提；
- 进行中订阅数、待确认候选、下载中/待整理数量、最近错误；
- 每个定时任务的上次结果与下次运行时间；
- 启动自检结果。

## 2. 新建订阅

入口有两个：

1. **搜索页**：输入关键词搜索 M-Team，勾选一条结果后自动预填标题、年份、ID、类型、季号。
2. **豆瓣榜单**：浏览剧集/电影/综艺，点「订阅」跳转预填。榜单只读公开页面，
   不需要豆瓣账号；季号从标题推断（如「老友记 第二季」→ 第 2 季），综艺按剧集处理。

订阅字段：

| 字段 | 说明 |
|---|---|
| 标题 | 建议使用中文名；可用豆瓣原名/别名辅助匹配。 |
| 类型 | 电影 / 剧集，创建后不可修改。 |
| 年份 | 用于过滤同名作品。 |
| 季号 | 剧集季号，参与发布名集数映射。 |
| 豆瓣 ID | 可选；用于匹配与补全信息，不需要 TMDB。 |
| 检查间隔 | 该订阅的自动检查间隔（分钟）。 |
| 起始集 | 可选；只想追新集时填写。 |
| 集数范围 | 可选；已知总集数时填写，便于补齐。 |
| 媒体库分类 | 如「动漫」「纪录片」；默认模板会把 `Movies` / `TV` 替换为该分类。 |
| 自动下载最优条目 | 关闭时只生成候选；可随时在订阅行切换。 |

订阅页分「进行中」「已完成」两个页签：剧集目标集数全部整理完成（电影整理完成）后，
订阅会自动移到「已完成」，仍可编辑、检查、恢复为进行中或删除。

删除订阅会软删除该订阅并清理其候选；该订阅的任务不再出现在任务页和仪表盘计数里。
已下载文件和 qB 保种保留，仍由保种策略按分享率/做种时长管理。

## 3. 检查与候选

点订阅行的「检查」立即搜索并写入候选。手动检查的第一个关键词不等待 20 秒限速槽位；
需要换用原名/别名再搜时，后续关键词最多等待 20 秒，仍被限流则保留已搜到的结果继续评估。

「候选」页默认展示每个订阅的**最优种子组合**：

- 排序先看「仍缺已播集数」（尚未上线的集不算缺口），再看评分、免费、做种；
  集数完全未知时按评分。
- 一个种子覆盖不了所有已播集数时，组合会包含多条，标记「最优 1/N、2/N」；
  后续新集出现且有对应发布后会自动追加。组合内每条都可单独「下载本条」。
- 只有 `Sxx`/`Complete` 而无法解析集数的「合集」只作兜底，不会挤掉能确认集数的种子。
- 最优页展示覆盖全部已播缺口的完整组合，不受单次抓取条数和日预算限制；
  实际自动下载仍分批、按预算执行。
- 「查看全部候选」用于人工比较；筛选栏可按订阅过滤，操作后保持筛选状态。
- 「忽略」永久生效，后续自动检查不会复活该种子；评分不足的条目以
  `ignored(auto)` 保留，可「恢复为候选」。
- 「删除《订阅名》的候选」删除筛选下所有候选（含全部候选页里未展示的备选），
  只删候选记录，不影响已下载任务；勾选「同时删除已忽略记录」才会清除已忽略条目。

订阅行的「下载最优」会补齐**所有已播出但未下载的集数**：

- 有一条能确认覆盖范围的累积合集（`全N集` / `更新至N集` / 带区间的整季包）时只抓这一条；
- 只有零散单集或区间包时，自动抓取多条，每次最多 `max_grabs_per_check` 条，
  并受日下载预算限制，剩余部分后续检查继续补齐。

检查完成后若「抓取 0」，提示会说明原因：未开启自动下载、`DRY_RUN` 开启、
已播出集数均已下载、还有集数没有可覆盖且在预算内的候选，或最后一条抓取错误。
同样的 `grab_note` 会写入事件日志。

## 4. 搜索页手动抓取

「搜索」页可按关键词搜索并手动下载：结果行选择订阅后点「下载」。

- `DRY_RUN=true` 时只记录候选，不调用取种接口，也不写入 qB。
- 真实抓取消耗 1 次取种预算（默认 60/24h）。

## 5. 任务页

「任务」页分两个页签：

- **下载与整理**：下载中（进度/速率）、待整理、整理失败（错误 + 重试）、做种中
  （时长/分享率），以及删除操作。
- **已整理**：单独列出已整理完成的任务，可「重新整理」或查看归档结果。

默认隐藏候选与已忽略记录；需要临时查看时点页签顶部的「显示候选与已忽略 (N)」。

「删除」会同时删除 qB 种子与文件，并把任务软删除为 `deleted`、从所有任务视图移除
（保留审计记录）。未整理的分集会被释放，后续检查可重新抓取；已整理分集保持不变。

整理把完成任务硬链接到媒体库，并按模板重命名。修改媒体库分类或模板后，可对已整理
任务点「重新整理」：会在新位置建链并移除本任务旧位置的链接，下载副本不受影响。

## 6. 豆瓣榜单

- 剧集 / 电影 / 综艺 × 近期热门 / 最新上线 / 高分优先。
- 可按单一年份或年代、类别（喜剧、悬疑、纪录片、真人秀等）筛选。
- 每页可选 20/50/100 条，显示总条数与总页数，支持上一页/下一页和输入页码跳转。
- 筛选条件（类型/排序/年份/类别/每页）写入会话：从导航回到「豆瓣榜单」仍按上次
  条件展示；点「清除筛选」恢复全部。
- 选中的类别会自动填入新建订阅的「媒体库分类」（豆瓣的「动画」映射为「动漫」），
  可在订阅页修改或清空。

## 7. 定时任务

`SCHEDULER_ENABLED=true`（默认）时，进程内 APScheduler 运行：

| 任务 | 间隔 | 行为 |
|---|---|---|
| `tick_subscriptions` | 60s | 检查到期订阅；每个订阅仍受自身 `interval_min` 与失败退避限制 |
| `poll_torrents` | 60s | 同步 qB 进度，完成后进入待整理 |
| `organize_pending` | 30s | 整理已完成任务到媒体库 |
| `profile_guard` | 15min | 刷新分享率快照，低于阈值时切换为「仅免费」或「暂停」 |
| `seed_cleanup` | 1h | 清理达标做种任务；磁盘超阈值时加速清理 |
| `prune` | 每日 04:10 | 清理过期候选、自动忽略、25h 前预算记录、30 天前事件/快照 |
| `daily_digest` | 每日 09:00 | 推送待确认候选、下载中、待整理、错误与磁盘摘要 |

手动检查与定时检查共用一把锁，不会并发搜索。

## 8. 分享率护栏与清理

- `ratio_pause_nonfree`（默认 0.8）：分享率低于此值只允许免费种子。
- `ratio_pause_all`（默认 0.6）：分享率低于此值暂停全部抓取。
- 解析不到分享率时保持原状态，不会误停。
- `disk_pause_percent`（默认 90）：磁盘达到阈值时暂停非免费抓取；只有免费种子仍可下载，
  同时 `seed_cleanup` 优先清理做种最久且已达标的任务。
- 清理条件：已整理 + 做种 ≥ `min_seed_hours`，且分享率 ≥ `min_ratio` 或做种 ≥
  `max_seed_hours`；仍处于 active 且未追完的剧集会被保留。
- 自动清理只删 `organized` 任务并保留分集已整理状态，不会重复下载。
- `DRY_RUN=true` 时只返回将要删除的列表，不调用 qB 删除。

## 9. 通知

`/settings` 的 `notify_config` 支持：

```json
{
  "wecom": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...",
  "serverchan": "https://sctapi.ftqq.com/xxx.send",
  "smtp": {
    "host": "smtp.example.com",
    "port": 465,
    "user": "bot@example.com",
    "password": "...",
    "to": "me@example.com"
  }
}
```

通知 5 秒超时、失败只记日志，不影响抓取/整理。触发场景：抓取成功/失败、整理失败、
分享率护栏切换、API Key 失效、磁盘告警、每日摘要。

## 10. 评分与选种偏好

默认评分偏好 4K（`2160p`），同分辨率下 10bit 优先；电影额外偏好带中文配音
（国语/国配/中配/普通话等）的版本。这些是**评分偏好**而非硬性过滤，没有 4K、10bit
或国语标记的资源仍可入选。硬过滤、评分和最优组合的详细规则见
[详细设计 §7](详细设计.md#7-解析与匹配)。

## 11. 设置页

「设置」页可调整评分阈值、候选数量、预算（含 24h 搜索预算，留空恢复 `.env` 默认）、
保种清理、分享率/磁盘护栏、命名模板、搜索映射、通知，以及更换 MT API Key / qB 密码
（留空保持不变，可清除覆盖回退到 `.env`）。保存后立即生效。

## 12. 日志

「日志」页按级别/模块查看事件。抓取、整理、登录、定时任务失败都会记录；
API Key、qB 密码、SMTP 密码等敏感值会被掩码。
