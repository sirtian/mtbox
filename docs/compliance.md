# 合规说明

> 本文是项目的行为边界说明，不构成法律意见。使用者需自行确认账号规则与当地法律。

## 1. 与站点/厂商的关系

mtbox 是独立的第三方工具，**与 M-Team、豆瓣、qBittorrent、极空间均无关联**，
未获其授权或背书。项目名称、界面文字中的第三方名称仅用于说明兼容性，
相关商标归各自所有者。

## 2. M-Team 使用边界

- **只使用官方 Open API**，认证方式仅为 `x-api-key`（存取令牌）。
- **不使用站点 Cookie，不调用 `/login`、`/admin/**`、`/apikey/**` 等网页/管理接口**，
  不模拟网页登录，不绕过 Cloudflare 或人机验证。
- 尊重站方的频率与预算限制：默认搜索 400 次/24h、取种 60 次/24h；搜索最小间隔
  默认 0（不限速），可在设置页配置。建议对频率敏感的账号设置 20 秒或更高，
  调高预算或调低间隔前请确认符合你的账号等级与站点规则。
- 分享率偏低时程序会自动切换为「仅免费」或暂停抓取；这不能替代你定期登录网页、
  维持账号活跃与分享率的责任。
- 账号安全、种子来源合法性、下载内容的使用范围由账号持有人负责。
- 本项目不提供、不托管、不分发任何种子或影视资源，也不包含站点数据。

## 3. 豆瓣

- 豆瓣榜单只读取**公开页面**，不需要豆瓣账号、Cookie 或 API Key。
- 页面结果会缓存（默认 10 分钟），避免频繁请求；请勿把缓存时间调得极短或
  进行高频抓取。
- 豆瓣页面结构变化可能导致解析失败，这属于兼容性问题，不是对站点的绕过。

## 4. 版权与内容

- 本项目只负责搜索元数据、调用下载器与整理文件，**不判断下载内容的版权状态**。
- 下载、保存、传播影视内容可能受著作权法与站点规则约束；请只处理你有权访问的内容，
  并遵守所在地区的法律。
- 不要使用本项目批量抓取、重新分发或公开分享受版权保护的内容。
- `DRY_RUN=true` 模式可在不下载的情况下验证匹配与整理逻辑，建议首次部署时使用。

## 5. 隐私与数据

- 所有数据保存在本地 `DATA_DIR` 与 `.env`，**没有遥测、统计或远程上报**。
- 出站请求仅限：你配置的 M-Team API、qBittorrent Web UI、豆瓣公开榜单，
  以及你主动配置的通知渠道（企业微信/Server酱/SMTP）。
- 设置页保存的 MT Key、qB 密码、通知密钥以明文存放在本地 SQLite；页面不回显，
  日志会掩码。请限制 `DATA_DIR` 权限并对备份加密。
- 管理端密码以明文存放在 `.env`；请勿提交 `.env`、数据库或镜像构建产物。
- 本工具是单用户、内网工具，不提供多租户或多用户隔离。

## 6. 安全研究

- 欢迎私下报告安全问题，流程见 [SECURITY.md](../SECURITY.md)。
- 请勿在公开 issue 中粘贴 API Key、密码、Cookie、完整 `.env`、数据库或未脱敏日志。
- 请勿使用本项目对站点进行压力测试、撞库、绕过风控或任何未授权测试。
